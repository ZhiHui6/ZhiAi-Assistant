操作指南

快速上手 智爱小助手

拖入文件即可收纳，点「新建」即可记录，设置改动会自动保存；常用操作都在下方。

快速开始

面板从上到下依次是日历、快捷启动和六个标签页：随记、待办、收纳、计时、关机、用量。功能区顺序固定，不能拖动调整。

把文件、文件夹或程序快捷方式拖到面板上：落到快捷启动是添加程序，落到其它位置会切到收纳页并收藏起来；挂载常用文件夹请在收纳页点「+ 挂载」选择。

顶栏齿轮打开独立的设置窗口，设置、帮助与关于都在其中，改动会自动保存。

显示与收起

贴边自动隐藏开启时，鼠标靠近屏幕边缘即展开，离开后约 0.2 秒收起；开启「减少动画效果」后立即收起。收起后边缘仍露出书签条，鼠标移到边缘即可再次展开。

关闭自动隐藏后侧边栏常驻，用顶栏「收起」按钮或 Esc 手动收起；手动收起后，点击边缘书签展开。

图钉按钮仅在贴边自动隐藏开启时出现，钉住期间不会自动收起；取消钉住或重启后恢复自动隐藏。

托盘图标左键只唤出面板，不会收起；右键菜单提供显示或收起、钉住、贴边自动隐藏、开机自启、设置与退出。

随记

点「新建」立即生成一张空白便签并开始输入，停手约半秒自动保存；回车结束编辑，Ctrl+Enter 另起一段，Shift+Enter 只换行。

正文里以 # 开头的词会成为标签，顶部搜索框可同时匹配正文与标签；结果中置顶的排前面，其余按更新时间倒序。每张便签可置顶或删除。

悬停便签时，时间行右端出现 9 个颜色点（含默认），可标记颜色；编辑过程中不显示。按 Ctrl+K 可直接定位到搜索框。

待办与日历

今天只显示今天到期；本周按自然周统计未完成；逾期单独列出；未完成包含无日期与未来任务；已完成按完成时间倒序，默认显示最近 50 条，可展开更早。

在当前视图新增时会自动归入合适位置：逾期与已完成视图会先切回今天，本周视图创建今天到期任务；未完成视图创建无日期任务。

待办点击标题进入编辑，回车保存，Esc 取消；完成、删除后列表会保留当前滚动位置。

删除待办后 4 秒内可通过底部提示撤销；日历点选日期可直接查看或新增当天任务，节日名被省略时悬停可看完整说明。

收纳与挂载

「+ 分组」新建收藏分类，双击分组标题改名，右键删除；条目可以拖到其它分组，也能在组内调整顺序。

「+ 挂载」选择常用文件夹后可在同一页逐级浏览，用顶部面包屑或「返回收纳」退出；挂载条目右键可把它收纳到侧边栏。

删除分组会连同组内条目一起删除，操作前请确认。

快捷启动

快捷启动位于日历与标签页之间，可在设置中调整列数、行数、图标大小与名称显隐，或整块隐藏；超出「列 × 行」的程序可在区块内左右滚动，名称过长会省略，悬停显示完整名称。

顶部分类可切换与新建；右键分类可重命名或删除。把程序或快捷方式拖入即可添加，右键条目可启动、在资源管理器中显示、重命名、移到其它分类或移除。

计时与关机

计时页的闹钟可设时间、标签与每天重复，到点会展开面板并弹出提示；单次闹钟触发后会自动停用。倒计时支持时、分、秒输入与 5、10、15、25、45、60 分钟预设，最长 24 小时，收起面板后仍继续计时。

闹钟与倒计时各自可选铃音：内置 10 种、可试听，也可选静音或自选 WAV 文件。

关机页可按分钟倒数或指定时间安排，需二次确认；不足 60 秒会按 60 秒执行，最长 7 天，到点前可随时取消，实际关机由 Windows 执行。

用量与签到

用量页汇总 Qoder、WorkBuddy、Trae 的额度、重置日期与更新时间，「刷新全部」重新读取，「一键签到」为支持的平台领取签到奖励。

设置中的「自动签到」让已登录的平台每天自动签到一次，失败当天最多重试 3 次；用量面板顶部只显示当前状态。首次进入会先显示使用前确认，未登录时可在卡片内用浏览器登录或从客户端载入。

「刷新全部」会跳过未登录的平台；「一键签到」只为当天可领取的平台签到，没有可签到的平台时会提示。

数据与备份

存储位置支持系统应用数据、随程序存放与自定义路径；切换时会复制现有数据到新位置并自动重启，原位置保留不动。

数据保存在「设置 → 数据 → 存储位置」指定的目录，采用 JSON 原子写入并保留 .bak 备份；无法读取的旧文件会转存为 .corrupt。

导出备份时可勾选要包含的内容；导入时只覆盖所选类别，导入前会自动留一份完整备份，完成后关闭设置窗口，侧边栏在运行时会自动重启。

用量登录凭据由 Windows 用户加密保存，换机或换用户导入后会失效，需要重新登录。

设置 → 数据 → 完全重置 需在弹窗输入「完全重置」才能确认，会退出侧边栏、取消已安排的关机、关闭开机自启并删除当前存储位置的全部数据，操作不可撤销。

更新程序

在设置窗口的「关于」页点击检查更新，程序会读取 GitHub Releases 的最新版本。发布包带校验信息时可下载并自动替换；缺少校验文件时只能前往发布页手动下载。

内置更新会先关闭侧边栏、校验文件哈希、替换程序并自动重启；数据目录与设置不受影响。

自动检查会在启动时与每 6 小时静默进行一次，发现新版本会在侧边栏顶部提示；可在关于页关闭自动检查。

快捷键与设置

默认全局热键为 ctrl+alt+space，可在设置 → 窗口与启动 中修改；写法是用 ctrl、alt、shift、win 加「+」连接主键，主键支持字母、数字、空格、反引号与 F1 至 F12，且必须带至少一个修饰键。

启动时若首选组合被占用，会依次尝试备用组合并在托盘提示；在设置中改成被占用的组合不会自动回落，只会提示注册失败。设置窗口中的改动实时预览并自动保存，关闭窗口不会回滚；侧边栏未运行时，部分设置会在下次启动生效。
